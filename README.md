# A Visual Introduction to Algebraic Varieties

An eight-page visual primer by Benjamin Michael Haire.

- [Published booklet and curve lab](https://theisegoria.github.io/algebraic-varieties-introduction/)
- `report.pdf`: the A4 booklet
- `report.tex`: the editable LaTeX source
- `curve-lab.html`: an interactive smooth-to-singular cubic explorer

The booklet introduces zero sets, ideals and radicals, the Nullstellensatz, tangent spaces and singularities, coordinate rings, regular maps and normalization, and projective closure.
